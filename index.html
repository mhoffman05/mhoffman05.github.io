About

I'm a Biology major and Digital & Computational Studies minor at Bates College, and a runner on the Bates cross country and track & field teams.

Running is where my interest in sports science started. Endurance athletes are surrounded by products and metrics that promise to make us faster, and most of them are sold with "science" that falls apart when you look closely. I use biology to understand what the body is actually doing, and computation to test whether the claims hold up.

This portfolio collects my work in DCS: projects, notebooks, and the workflow I use to build them.

DCS 105 · Calling Bull: Data Literacy and Information Science

Running on Bad Data

A website debunking endurance-based sports science product claims. I used visual BS-busting, BS-busting with R, and public BS-busting to take apart three examples: Nomio (weak studies and an unlabeled graph), sodium bicarbonate from Maurten and Bicarb Shop (race-time predictions far beyond what controlled studies show), and Garmin & Coros watches (VO₂ max and race predictions treated as measurements when they're algorithm estimates).

DCS 236 · VECINA: Civic Data Design With and For Community

VECINA

VECINA is a Woonasquatucket River Watershed Council platform that helps Providence, RI residents find resources and advocate for their neighborhoods. Our class drafted a new section of the website and cleaned the project's existing data in Google Sheets so the community could use it.

Workflow

Every project ends up on GitHub. Here's how it gets there.

Claude → VS Code → GitHub

I plan and debug with Claude, write code in VS Code, and commit and push to GitHub. This site was built this way.

Gemini → Colab → GitHub

Notebooks run in Google Colab with Gemini helping as I go, then get saved straight to this repo's notebooks/ folder.

R → RStudio → GitHub

Data analysis in R, like the BS-busting in DCS 105, lives in RStudio projects tracked with Git.
